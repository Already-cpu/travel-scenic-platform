行旅志旅游景点网站（一键运行版）
================================

一、运行前准备
1. Windows 10/11。
2. 安装 Java 8 或更高版本。
3. 安装 MySQL 8 或更高版本，并启动 MySQL 服务。
4. 请先完整解压压缩包，不要直接在压缩软件内运行。

二、启动方式
双击“一键启动.bat”。脚本会自动完成：
- 检查 Java 和 MySQL；
- 使用独立 MySQL 数据库 travel_website；
- 首次运行时自动导入 database/travel_website.sql；
- 启动后端与已经打包好的 Vue 页面；
- 自动打开浏览器。

默认数据库账号密码为 root/root。如果本机密码不同，脚本会提示输入，密码不会显示在屏幕上。

三、访问地址
用户端：http://localhost:8080/
管理端：http://localhost:8080/admin/login

管理员账号：admin / admin123
演示用户账号：13800138000 / 123456

四、停止方式
双击“停止项目.bat”。关闭浏览器不会自动停止后台程序。

五、常见问题
1. 提示找不到 Java：安装 Java 8+，并勾选添加到 PATH，或安装到默认目录。
2. 提示找不到 MySQL：安装 MySQL 8+ 和命令行客户端。
3. MySQL 连接失败：确认 MySQL 服务已启动、端口为 3306，并输入正确账号密码。
4. 8080 端口被占用：关闭占用该端口的软件后重新启动。
5. 日志位置：runtime/backend.log 和 runtime/backend-error.log。

本项目不使用 H2；业务数据全部保存在独立 MySQL 数据库中。
